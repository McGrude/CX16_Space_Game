# Historical design archive

These documents preserve earlier thinking and source material. They may conflict with one another, reference missing tools, or describe features that were never implemented. They are not active agent instructions.

Use `../PROJECT.md`, `../ROADMAP.md`, and `../phases/` for current direction. Fixed future factions, predetermined milestone dates, living alien factions, and old game-state proposals are historical alternatives unless explicitly adopted in current documents.

Former shell launchers are retained for provenance, not execution. They use old paths, interpreter assumptions, and in one case a misspelled filename.
